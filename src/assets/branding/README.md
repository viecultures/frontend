# THƯ MỤC BRANDING & LOGO (src/assets/branding)

Thư mục lưu trữ logo, biểu trưng và bộ nhận diện thương hiệu VieCultures.

## Các file quy chuẩn cần bổ sung:
- `logo-viecultures.png` (Khuyên dùng): File logo thương hiệu VieCultures nền trong suốt (PNG/SVG), dùng cho Navbar và Footer.
- `logo-symbol.svg`: Biểu tượng văn hóa thu nhỏ dùng cho mobile favicon/icon.
- `logo.jpg`: Logo hiện tại đang được sử dụng làm fallback.
