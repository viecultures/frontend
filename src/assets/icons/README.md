# THƯ MỤC ICONS (src/assets/icons)

Thư mục lưu trữ các icon vector SVG tùy biến theo phong cách văn hóa Việt Nam.

## Các file SVG kiến nghị:
- `icon-search.svg`: Icon kính lúp nét mảnh thanh lịch cho Navbar.
- `icon-user.svg`: Icon tài khoản cá nhân cho Navbar.
- `icon-lotus.svg`: Biểu tượng hoa sen trang trí.
- `icon-book.svg`: Biểu tượng quyển sách từ vựng.
