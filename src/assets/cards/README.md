# THƯ MỤC CARDS ASSETS (src/assets/cards)

Thư mục lưu trữ hình ảnh bìa của 4 chuyên đề văn hóa thuộc chuyên mục "Bốn miền khám phá" (Explore Section) và các card bài học tương lai.

## 4 File ảnh bìa chuyên đề cần bổ sung (theo document/design.md):
1. `card-van-hoa.webp`: Bìa thẻ "Nếp sống & văn hóa" (cảnh sinh hoạt, mái đình làng quê, nếp nhà Việt).
2. `card-truyen-thuyet.webp`: Bìa thẻ "Truyền thuyết" (huyền sử dân gian, Sơn Tinh Thủy Tinh, Lạc Long Quân - Âu Cơ).
3. `card-am-thuc.webp`: Bìa thẻ "Ẩm thực" (mâm cơm Việt, bát phở truyền thống, hương vị ba miền).
4. `card-le-hoi.webp`: Bìa thẻ "Lễ hội & sắc màu" (hội làng, lễ hội đèn lồng, tranh Tết Đông Hồ).

> **Kích thước kiến nghị:** Tỷ lệ 4:3 (ví dụ 600x450px hoặc 800x600px), định dạng WebP nén chất lượng cao.
