# THƯ MỤC HERO ASSETS (src/assets/hero)

Thư mục lưu trữ hình ảnh, video và đồ họa hiển thị trên màn hình đầu tiên (Hero Section).

## Các file quy chuẩn cần bổ sung:
- `hero-illustration.webp`: Tranh mỹ thuật trung tâm miêu tả người phụ nữ Việt Nam trong tà áo dài truyền thống và hoa sen (tỷ lệ 4:3 hoặc 16:9, tối ưu WebP).
- `icon-book.webp`: Icon quyển sổ từ vựng cho Widget "Discover / Khám phá" (kích thước 64x64px hoặc 128x128px, nền trong suốt).
- `banner.webm`: Video banner chạy nền khí quyển (đã có sẵn).
