# Owl demo assets

Original owl direction and reaction atlases from https://github.com/nilbuild/page-mascot,
downloaded from https://koboyo.com/page-mascot/mascots/ on 2026-10-16.

Copyright (c) 2026 Kamran Ahmed. Distributed under the MIT license included in
`page-mascot-LICENSE.txt`. Atlases are unchanged.

The demo uses page-mascot for cursor tracking and click reactions, and reuses atlas
cells with CSS motion for simulated talking, celebration and sleep. It does not
provide generated animation frames or audio/phoneme synchronization.
